# 2026 春晖中学校运会 · 摄制工作引导系统

本文档为浙江省春晖中学 2026 年校运会（2026SportsMeet）摄制团队的现场工作引导系统总控中心。本系统旨在帮助全体 21 位在岗成员（高一、高二摄制组）、后期剪辑团队以及统筹人员，在运动会全周期内快速获取操作指引、标准作业流程（SOP）与应急预案。

---

## 一、系统架构与模块导航

本工作引导系统划分为**希沃白板 Web 交互系统**与**七大执行操作规范手册**，覆盖赛前动员、赛场调度、拍摄实操、突发应急到后期流转的全流程：

### 🖥️ 核心交互系统（希沃白板专用）
- **[工作引导系统·希沃白板触控交互看板 (index.html)](file:///Users/fuzihao/Desktop/2026SportsMeet/工作引导系统/index.html)**
  - **赛程时间轴 (时间)**：按 10.8 Day 1（开幕式/飞人初战）、10.9 Day 2（速度决战/接力狂欢）、10.10 Day 3（耐力巅峰/闭幕荣光）高亮展示具体起止时段。
  - **官方比赛项目 (比赛)**：精确对齐 64 页官方秩序册与竞赛日程表，包含组别、道次与项目大类。
  - **在岗团队人员 (人员)**：严格对齐 21 人排班名单，支持 21 位同学姓名一键触控点名查岗与筛选。
  - **现场核心流程 (内容)**：清晰描述各赛段开赛流程、重点竞赛节点与现场交接任务。
  - **专业机位提示 (拍摄提示)**：提供 4K 120fps、连拍 1/2000s、推荐镜头焦段、构图站位与白色跑道 1 米安全线要求。
  - **社团参赛避让特别预警**：显眼红框提示沈栋忆、丁子妍、陈怀恒等 6 位社团参赛成员提前 30 分钟离岗检录与专机盯防安排。
  - **希沃白板触控优化**：超大触控按键、高对比度大屏排版、支持一键全屏演示。

## 三、现场三大铁律

1. **连拍打星，在精不在多**：严禁无脑连拍堆砌无用废片。比赛间隙务必即时回看并在机内打星（Rating 1~5星），降低废片率，提升有效镜头密度。
2. **拷卡三级目录规范**：素材交接严禁随意存放，必须严格按 `日期 / 比赛项目 / 机型(拍摄者)` 归档。
3. **突发意外绝不关机**：赛场摔倒、脱力倒地、交接掉棒时严禁移开镜头，记录同伴飞奔搀扶、递水擦汗等真实感人画面。
