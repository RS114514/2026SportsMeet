# 06 赛场突发状况与应急处置手册

本文档针对校运会期间可能发生的设备故障、恶劣天气、赛场意外以及人员调度突发情况，制定明确的应急处置标准与响应链路。

---

## 一、设备与硬件突发故障处置

```
 ┌─────────────────────────────────────────────────────────────┐
 │                     设备突发状况分类处置                     │
 └─────────────────────────────────────────────────────────────┘
          │
   ┌──────┴───────┬──────────────┬──────────────┐
   ▼              ▼              ▼              ▼
[存储卡写满/报错] [电池红格告急]  [机身死机卡死]  [云台电机抖动/过热]
   │              │              │              │
 立即换备用卡   示意搭档接力   强制拔插电池   双击扳机键复位
 故障卡妥善入盒 场务送充备用   检查镜头触点   严重时转纯手持
```

### 1. 存储卡写满或读写报错（Card Error / Write Protected）
- **现象**：屏幕提示“存储卡已满”或“无法写入存储卡”。
- **处置步骤**：
  1. 立即关闭相机电源，取出故障卡放入随身防静电卡盒，**严禁再次强行通电写入**；
  2. 换上随身备用卡；若无备用卡，立即向附近同组搭档示意借用，或微信/呼叫场务协助同学（陈玥潼、王艳）从大本营取卡。

### 2. 电池突然电量告急（红格闪烁）
- **现象**：电池电量仅剩 1 格并在闪烁，高帧率录制极易中途断电损坏当前视频文件。
- **处置步骤**：
  1. 趁当前组别尚未发车，立即完成当前镜头收尾（保持 2 秒静态落幅后按停录制）；
  2. 关机换上随身备用满电电池；
  3. 将耗尽电池电极朝下收好，中午/傍晚统一归还社团活动室充电。

### 3. 相机死机或镜头卡死
- **现象**：屏幕画面冻结、按任何按键无响应。
- **处置步骤**：
  1. 迅速将机身电源开关拨至 OFF；
  2. 若仍无反应，直接打开电池仓盖，**拔出锂电池等待 5 秒后重新插入**；
  3. 顺便检查镜头卡口是否锁紧到位，重新开机通常可恢复正常。

### 4. 稳定器或云台电机剧烈抖动 / 报错瘫软
- **现象**：三轴稳定器出现高频啸叫抖动，或电机过热突然失去力矩垂头。
- **处置步骤**：
  1. 快速双击稳定器扳机键（回中复位）；
  2. 若仍抖动，检查手机夹/微单快装板螺丝是否松动导致重心偏移；
  3. 无法现场排除时，果断关闭稳定器电源，**直接拆下相机改为纯手持拍摄**，切勿因摆弄稳定器而错过比赛关键瞬间。

## 二、恶劣天气与环境应急措施

### 1. 突发雷阵雨 / 飘雨
- **首要原则：器材安全第一**。
- **处置步骤**：
  1. 摄影师立即拉起相机包内自带的荧光防水雨罩，套住背包与相机；
  2. 备用机位手持微单立即使用防雨大毛巾包裹机身与镜头卡口部位；
  3. 全员就近撤入主席台后侧雨棚、看台高层建筑走廊或大本营帐篷内避雨；
  4. **严禁在暴雨中裸露相机拍摄**，雨水渗入按键缝隙将造成电子元件永久短路。

### 2. 正午烈日暴晒与机身过热
- **现象**：长时间拍摄 4K 120fps 导致相机屏幕提示“温度过高即将关机”。
- **处置步骤**：
  1. 拍摄间隙翻开相机翻转屏，避免屏幕贴紧机身背板蓄热；
  2. 严禁将相机机顶在阳光下长时间暴晒，等待下一组比赛时使用浅色毛巾或遮光帽遮挡机身；
  3. 在无重要比赛时随手关闭机身电源，降低机芯发热。

## 三、赛场突发碰撞与意外事故处置

1. **规避碰撞伤害**：
   - 当短跑选手冲线后因惯性或脱力直冲机位方向而来时，**人身安全第一**，拍摄者应顺着跑道外侧顺势闪身让出缓冲通道，切勿死守原地或用机身去阻挡。
2. **遵守救援通道纪律**：
   - 现场发生运动员严重扭伤、中暑脱水或晕厥时，机位人员必须退至 2 米开外，绝对禁止围堵医疗志愿者与担架进出通道；
   - 配合赛场广播与当值裁判指引，保持现场专业秩序。

## 四、人员缺席与紧急补位机制

- 若某机位成员因突发身体不适、班级临时班会或其他突发情况需临时离岗：
  1. 必须第一时间在群内或电话联系现场统筹 **沈栋忆** 及总策划 **傅梓浩**；
  2. 由常备机动组人员（陈玥潼、张嘉炜、王艳、莫佩祥）迅速前往对应机位接收器材并顶岗；
  3. 严禁擅自脱岗导致机位出现空缺。
