# 04 素材拷卡交接与文件管理 SOP

本文档为校运会摄制团队素材备份、交接流转与目录命名的统一作业规范。全体在岗拍摄成员与负责拷卡的同学必须严格执行，防止素材错漏与数据丢失。

---

## 一、三级目录命名铁律

为确保后期剪辑师（视频一高光混剪组、视频二学生会宣传片组、视频三开幕式实况组）能够快速定位调用镜头，所有拷贝至主移动硬盘与电脑本地的素材，必须严格遵循以下三级目录结构：

```
主工程素材存储根目录/
  ├── 20261008_Day1/                      <-- 第一级：日期与天数
  │     ├── 00_开幕式多机位/              <-- 第二级：具体赛项或主题
  │     │     ├── CAM-A_正面全景(连辰毅)/ <-- 第三级：机位编号_机型(拍摄者)
  │     │     ├── CAM-B_台上大推拉(冯翼)/
  │     │     └── CAM-E_贴地手持(汪清晏)/
  │     ├── 径赛_高一女100米预赛/
  │     │     ├── Sony_A7M4(莫佩祥)/
  │     │     └── Pocket3(徐清来)/
  │     └── 田赛_高二女跳远决赛/
  │           ├── Nikon_Z6(丁子妍)/
  │           └── Canon_R6(金煜豪)/
  ├── 20261009_Day2/
  │     ├── 径赛_男女4x100接力决赛/
  │     │     └── ...
  │     └── 人文_学生会幕后双线/
  │           └── Fuji_XT4(池雨曦)/
  └── 20261010_Day3/
        └── ...
```

### 命名规范详解
1. **第一级（日期）**：统一格式为 `YYYYMMDD_DayX`（如 `20261008_Day1`、`20261009_Day2`、`20261010_Day3`）。
2. **第二级（赛项/主题）**：格式为 `项目大类_年级性别项目组别`（如 `径赛_高三男1000米决赛`、`田赛_高一女跳高决赛`、`人文_学生会幕后双线`、`00_开幕式多机位`）。
3. **第三级（机位与人员）**：格式为 `设备类型/机位编号(拍摄者姓名)`（如 `Sony_A7M4(莫佩祥)`、`Pocket3_延长杆(冯翼)`、`CAM-A_70-200(连辰毅)`）。

## 二、拷卡交接时间节点与流程

每日设立两个集中拷卡窗口，全员必须按时交卡，严禁私自将存储卡带回寝室或教室：

| 批次 | 时间窗口 | 地点 | 负责拷卡统筹人员 | 任务要求 |
| :---: | :--- | :--- | :--- | :--- |
| **午间批次** | `11:30 - 12:15` | 新媒体社活动室 | 莫佩祥、陈玥潼 | 收集上午全部径赛与田赛存储卡，完成前半程素材导出，对耗尽电池插电复充。 |
| **傍晚批次** | `17:15 - 18:00` | 新媒体社活动室 | 鲍奕帆、傅梓浩、张嘉炜 | 收集全天剩余素材，完成全量汇总，进行双重硬盘备份，并为次日拍摄清空卡槽。 |

### 现场交接流转步骤
```
  [拍摄队员交卡]
        │ (核对当场赛项名称与个人姓名)
        ▼
  [高速读卡器接入主控工作站]
        │ (新建标准三级目录)
        ▼
  [完整复制原卡全部素材 (DCIM及相关目录)]
        │ (等待进度条完成)
        ▼
  [右键属性核对：比对文件数量与总字节大小]
        │ (一致无误)
        ▼
  [同步镜像至备份移动硬盘 (双重保险)]
        │ (完成双重留存)
        ▼
  [将卡归还拍摄队员，或在相机机内执行格式化]
```

## 三、数据防丢与格式化红线

1. **绝对禁止在电脑上直接“剪切”文件**：拷贝时必须使用“复制”，严禁使用“剪切”。直接剪切若遇读卡器接触不良可能导致数据损坏不可逆。
2. **绝对禁止在电脑上右键删除单张照片**：电脑端删除易破坏存储卡文件索引结构，增加报错风险。
3. **格式化前双重验证**：
   - 只有确认素材已同时保存在“主控电脑本地硬盘”和“移动硬盘”两处独立介质中；
   - 并且抽查播放了 3~5 个视频与全尺寸照片正常打开后；
   - 才允许将存储卡装回相机，**在相机机身菜单内执行“格式化（Format）”**。
4. **照片与视频混录处理**：
   - 若单张卡内同时包含高连拍 RAW/JPG 照片与 120fps 视频，可在第三级目录下分别建立 `Photo` 与 `Video` 文件夹，或保持相机原生文件命名规范直接整体拷贝。
