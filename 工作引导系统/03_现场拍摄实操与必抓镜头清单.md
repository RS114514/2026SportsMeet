# 03 现场拍摄实操与必抓镜头清单

本文档汇总了赛场现场实操的关键方法、筛选技巧以及各赛项必抓镜头清单，供外景摄像师与摄影师随身对照执行。

---

## 一、机内打星筛选法（Rating 1~5星）实操

在高速连拍模式下，每位摄影师单日可能拍摄上千张照片。若不进行现场筛选，后期的选片工作将极其繁重。因此，必须严格落实“赛中间隙机内即时打星”机制。

### 1. 打星标准与级别定义
- ⭐⭐⭐⭐⭐ **5 星（决定性黄金瞬间）**：
  - 构图完美、焦点极为锐利、情绪张力拉满的顶级镜头（如：背弓越过横杆且横杆微颤瞬间、终点撞线仰天咆哮、脱力倒地后同伴飞奔拥抱送水）。
  - 该级别照片直接入选学校官方新闻特稿、主片定格封面与高光相册。
- ⭐⭐⭐⭐ **4 星（合格优质动作片）**：
  - 焦点清晰、动作舒展、光影正常的优质竞速与发力画面，作为主力剪辑与相册备用素材。
- ⭐⭐⭐ **3 星及以下（常规留存素材）**：
  - 动作完整但情绪一般或角度普通的画面，常规归档，不作优先展示。
- **无星（失焦/闭眼/遮挡废片）**：
  - 严禁在机内随手逐张删除（避免误删或打乱相机计数），交由电脑批量过滤。

### 2. 打星时间窗口
- 短跑每组发车间隔通常有 **30~45 秒** 准备时间；
- 跳远、跳高每位运动员试跳间隔有 **1~2 分钟** 间隙；
- 抓拍完毕后，立即利用该空隙按下相机回放键，右手单指轻点机身 `Rating`（评级）键，快速标定 4 星或 5 星。

## 二、“突发意外绝不关机”原则与拍摄技巧

校运会最能打动师生人心的画面，往往不是一帆风顺的冲刺，而是意外摔倒后的爬起、交接掉棒后的捡起追赶、拼尽全力撞线后的虚脱，以及同伴飞奔搀扶递水的真情流露。

```
 [突发摔倒 / 脱力倒地 / 接力掉棒]
                │
 ───────────────┴───────────────
 │ ❌ 绝对禁止的操作           │ ✔️ 正确专业的操作
 ├──────────────────────────────┼──────────────────────────────
 │ 1. 立即下意识按下关机/停止键 │ 1. 稳住呼吸，绝对保持录制开启
 │ 2. 尴尬移开镜头对准地面     │ 2. 镜头缓慢向前推进或变焦推特写
 │ 3. 大声喧哗叫嚷影响抢救     │ 3. 记录同伴飞奔搀扶、递水擦汗画面
 └──────────────────────────────┴──────────────────────────────
```

1. **稳住镜头，平稳跟推**：
   - 看到运动员摔倒或冲过终点线脱力扑倒在草坪时，双手紧扣相机与稳定器，切勿因慌张而晃动机身；
   - 顺势由中景缓慢切至特写，捕捉其胸膛剧烈起伏、脸上汗水与泥沙交织的坚毅神态。
2. **记录全景温情救助**：
   - 严禁拍摄令人难堪的走光或单纯痛苦画面，重点拍摄随之上前的温情场景：同班同学大步上前架起双臂、送上温水、医护志愿者蹲下喷洒云南白药喷雾、老师拍背宽慰。这些镜头是宣传片与高光主片的情感核心。

## 三、跑道外沿安全站位与避让走线

1. **绝对禁区**：
   - 塑胶跑道红色区域及白色跑道线为竞赛专用区域，严禁踏入；
   - 终点线延长线正前方 15 米内为运动员高速冲刺后的缓冲减速带，严禁正对站立，防止被脱力前冲的运动员撞倒。
2. **安全站位建议**：
   - **直道侧跟**：站立于外圈跑道外沿绿化或水泥硬化台阶边缘（距离跑道白线至少 1 米）；
   - **终点斜切**：站立于终点线斜后方 30° 角或看台低矮防护栏后方，既有纵深视觉，又能规避碰撞风险。

## 四、各赛项必抓镜头清单

### 1. 径赛类（100m / 200m / 400m / 800m / 1000m / 接力）
- **起跑准备区**：
  - 手部特写：钉鞋紧踩起跑器倒蹬、手指沾满镁粉撑地颤抖、弓步下沉；
  - 眼神面部：深吸气屏息、眼神死死咬住前方终点线、发令枪举起的剪影。
- **直道与弯道竞速**：
  - 摆臂特写：手肘高速前后拉扯、面部咬牙发力、发丝扬起；
  - 弯道倾斜：200m/400m 弯道进直道瞬间，身体向内倾斜的动态张力。
- **4×100m 接力区**：
  - 交接棒刹那：后棒拼死前推、前棒后伸右手掌心上翻、铝合金接力棒拍入掌心的清脆瞬间；
  - 起动卡点：接棒队员听到喊声起跑弹射出击的背影。
- **终点冲刺线**：
  - 极限压线：胸部前倾压线撞击红绸缎带、双臂后扬、撕心裂肺的怒吼；
  - 撞线后群像：整班同学跨过草坪围拢拥抱、击掌相庆。

### 2. 田赛类（跳高 / 跳远 / 铅球 / 立定跳远）
- **跳高（背越式）**：
  - 助跑节奏：踏步节奏由慢到快，起跳腿坚决踏地卡点；
  - 过杆背弓：身体横卧悬空于横杆上方，背部形成反弓，头发下垂；
  - 横杆微晃：身体越过落下瞬间，横杆在支架上轻微震颤却稳稳不落。
- **跳远（沙坑）**：
  - 踏板瞬间：起跳脚精准踩在白板边缘，鞋底橡胶形变；
  - 腾空与落坑：双腿前伸腾空滑行，双脚破沙切入瞬间沙粒向四周喷射炸裂的慢动作。
- **铅球（力量美学）**：
  - 力量蓄积：锁骨窝紧贴沉重铅球，全身下蹲扭转蓄力；
  - 出手咆哮：右腿蹬伸送髋、右手手指猛烈拨球出手伴随一声怒吼、铅球重重砸击泥地溅起泥星。

### 3. 赛场幕后与学生会人文抓拍（视频二支撑素材）
- **工作证细节**：洗得发白或沾着汗水的工作证挂绳在锁骨前晃动、别在胸前碰撞；
- **裁判助理**：蹲在终点线旁手持机械秒表拇指悬停、低头在防风夹板上记录数字；
- **成绩传递**：手攥成绩单在人流夹缝中疾步小跑送达公告栏；
- **广播台**：广播室桌面上堆满红笔画勾的加油小纸条、播音员按开话筒按钮发声；
- **大本营**：各班级三五成群抬着长条椅穿过林荫道、草坪上搭起遮阳伞的忙碌身影。
