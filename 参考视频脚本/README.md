## 落地建议（2026SportsMeet 拍摄与制作指南）

1. **组合拳宣发矩阵**：
   - **快节奏引爆（赛前/赛中）**：以方案 06（三维地标跟踪与极速卡点）作为开幕预热与首日高燃短视频，在抖音、视频号与朋友圈快速吸睛引流。
   - **大片全景（闭幕）**：以方案 02（高燃快剪 MV）作为运动会闭幕当日的官方宣发主视频，展现全校/全院拼搏群像与最高荣誉。
   - **单项焦点（赛程实时）**：以方案 01（奥运转播风格）作为百米飞人大战、4×100米接力决赛、拔河决赛的独立切片，强化赛事正规度与科技趣味感。
2. **机位配置推荐**：
   - **机位 A（航拍无人机）**：负责起跑俯视、终点正上方撞线判定俯拍、全场景大调度，以及预留平稳航线供后期三维摄像机反求跟踪。
   - **机位 B（长焦特写机位）**：配置 70-200mm 大光圈，负责捕捉运动员面部青筋、眼神杀、交接棒与终点表情。
   - **机位 C（手持云台广角机位）**：贴地超低角度仰拍起跑爆发与终点撞线冲力。
