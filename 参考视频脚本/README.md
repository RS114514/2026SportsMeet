## 落地建议（浙江省春晖中学 2026 校运会实操指南）

1. **组合拳全周期宣发矩阵**：
   - **预热期（赛前 1-3 天）**：采用方案 06（三维地标与极速预告），结合白马湖、一枝春、象贤图书馆与经亨颐题写校训的三维立体跟踪字，引爆期待。
   - **赛程日（赛中高光推送）**：
     - **单项决战**：采用方案 01（奥运转播风格）制作“男子/女子 100 米飞人大战”、“4×100米接力”等重磅单项微视频；
     - **班级社交爆款**：采用方案 05（魔方抽色 Vlog）与方案 07（运动相机穿梭），由各班级新媒体委员抓拍班级趣味与温情切片；
   - **闭幕收官（赛后官方大片）**：结合方案 02（高燃混剪 MV）、方案 04（国旗仪仗交错）与方案 08（全流程集锦），推出 1-2 分钟的春晖 2026 校运会官方终极 Highlight 大片。

2. **摄制组器材与机位协同配置**：
   - **机位 A（高空航拍组）**：大疆 Mavic / Mini 系列，负责全场大俯冲、开幕方阵、90° 垂直俯瞰拔河直道、终点鹰眼判定。
   - **机位 B（长焦特写组）**：微单机身 + 70-200mm f/2.8 镜头，专职捕捉运动员眼神、肌肉紧绷、交接棒碰撞与跳高逆光剪影。
   - **机位 C（贴地广角组）**：手持微单 + 广角变焦 + 三轴稳定器，负责贴地 5-10cm 跟拍起跑、弯道与冲刺撞线。
   - **机位 D（运动相机穿梭组）**：Insta360 / GoPro 等运动相机，深入班级大本营、拔河人潮中心与跑道内圈，抓拍第一人称沉浸式高能量镜头。
