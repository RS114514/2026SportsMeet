# 浙江省春晖中学 2026 年校运会（2026SportsMeet）视频制作工程

本项目为浙江省春晖中学 2026 年校运会官方视听内容制作与策划全套工程。涵盖从前期官方赛程研判、现场多机位调度、分镜头脚本撰写，到后期剪辑包装、央视转播级包装与成品归档的全流程协同。

---

## 一、项目团队与职责分工

- **总策划与脚本统筹**：新媒体社策划组（统筹全套脚本框架设计、各片创意策划与主片剪辑统筹）
- **指导老师**：新媒体社指导老师（指导重点赛事转播与全社拍摄标准）
- **现场拍摄统筹**：现场摄制统筹组（负责根据策划脚本调配各年级机位人选与现场排班）
- **专属航拍飞手**：特约航拍机位（负责男子百米直道跟飞、终点垂直鹰眼判定及全场高空大景航拍）
- **新媒体社口播**：新媒体社口播主持组
- **社团梯队协作**：
  - **高二主力摄制组（2028 届）**：承担传统高光大片剪辑与核心赛事机位拍摄（贴地跟跑、长焦捕捉、终点冲刺）
  - **高一协助摄制组（2029 届）**：承担《学生会幕后工作宣传片（Vlog）》拍摄与后期剪辑支持

## 五、工作流与归档规范

1. **过程工作区隔离**：与具体视频制作相关的分镜草案、BGM 选型、素材清单统一存放在各自的 `视频0X_.../` 工作区内，避免在根目录堆积过程临时文件。
2. **定稿归档机制**：经团队确认定稿的完整交付版脚本，统一收录于 `成品脚本/` 目录。
3. **状态同步机制**：项目重大决策变动或阶段性成果完成时，同步更新 [需求梳理.md](file:///Users/fuzihao/Desktop/2026SportsMeet/需求梳理.md)。
