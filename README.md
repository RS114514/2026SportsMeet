# 浙江省春晖中学 2026 年校运会（2026SportsMeet）视频制作工程

本项目为浙江省春晖中学 2026 年校运会全套官方视听内容制作与策划工程。涵盖从前期赛程研判、现场多机位调度、分镜头脚本撰写，到后期剪辑包装、央视转播级包装与成品归档的全流程协同。

## 二、四大核心产出视频规划

| 视频项目 | 风格定位 | 主创分工 | 核心内容与技术要点 |
| :--- | :--- | :--- | :--- |
| **视频 1：传统高光混剪** | 高燃混剪 MV 风格 | 傅梓浩亲自负责后期剪辑 | 强节奏卡点、Beat Drop、升格慢动作、单项竞速高光群像，展现春晖学子拼搏与热血 |
| **视频 2：学生会幕后宣传片** | 纪实叙事 / Vlog 风格 | 傅梓浩脚本策划，高一同学后期剪辑 | 展现“看不见的赛场与奉献”，记录检录处、终点裁判助理、广播台、器材组等幕后奉献 |
| **视频 3：开幕式多机位实况片** | 全流程实况记录 | 社团多机位录制，多机位时间线剪辑 | 完整记录全校各班入场方阵、主席台全景与跑道特写，确保每个班级精彩呈现 |
| **视频 4：男子百米奥运解说短片** | CCTV-5 / 奥运电视转播规格 | 社团协同制作，冯翼重点航拍 | 对标郑铁百米决赛样片，涵盖选手道次条、直道跟拍、终点 Photo Finish 鹰眼慢动作判定与成绩大榜单 |

## 五、工作流与归档规范

1. **过程工作区隔离**：与具体视频制作相关的分镜草案、BGM 选型、素材清单统一存放在各自的 `视频0X_.../` 工作区内，避免在根目录堆积过程临时文件。
2. **定稿归档机制**：经团队确认定稿的完整交付版脚本，统一收录于 `成品脚本/` 目录。
3. **状态同步机制**：项目重大决策变动或阶段性成果完成时，同步更新 [需求梳理.md](file:///Users/fuzihao/Desktop/2026SportsMeet/需求梳理.md)。
