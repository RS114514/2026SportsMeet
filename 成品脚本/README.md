## 二、归档与交付规范说明

1. **成品集中归档原则**：本目录（`成品脚本/`）仅用于存放经过各方逐轮校对、推演并由用户最终确认定稿的交付版脚本，严禁存放过程草稿；
2. **过程工作区独立**：各视频制作前期的分镜草案、灵感记录、BGM 选型与机位讨论，均在各自的 `视频0X_.../` 工作文件夹中独立推进；
3. **状态双向同步**：每当有新视频脚本定稿归档，必须同步更新本项目总控文件 [需求梳理.md](file:///Users/fuzihao/Desktop/2026SportsMeet/需求梳理.md)。
