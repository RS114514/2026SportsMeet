# 2026 春晖中学校运会摄制排班总览表 (排班/)

本文档为 2026 年校运会（10月8日~10日）新媒体社摄制团队全部 19 位在岗成员（全量由高一、高二团队承担，高三全员免排班备考）的现场排班总汇。每个人均已生成独立可打印/手机查阅的电子排班文件。

## 一、重要全员集合与通知

1. **动员大会**：**10月7日（周三）12:30** 在社里（新媒体社活动室）召开全体动员会；
2. **开幕式集合**：**10月8日（周四）中午 12:30** 在社里集合！全员务必提前向班主任请好假，不参加方阵进场，直接投入摄制工作；
3. **高三同学免排班**：高三年级同学因备考不安排任何拍摄任务，但社团内高三参赛同学（任煜成、张慈恩等）在场上的比赛，在岗成员必须重点安排专机抓拍！
4. **有项目成员**：自己有单项比赛的同学提前 30 分钟交接器材去检录；其他成员负责专机盯防！

## 五、任务单印制守则（摄制、连拍精选与拷卡规范）

> [!IMPORTANT]
> **【任务单底部印制版·摄制与拷卡守则】**
> 1. **连拍打星·在精不在多**：严禁盲目长按连拍堆积废片！赛隙务必回看机内打星（Rating 1~5星），优先留存神态坚毅、动作最高点的高信息密度与有效镜头。
> 2. **拷卡三级目录规范**：素材交接严禁随意散落，必须严格遵循三级目录结构：
>    `日期` / `比赛项目` / `机型(拍摄者)`
>    *例：`10月8日/高一男100米预赛/A7M4(莫佩祥)/` 或 `10月9日/男子跳高/Pocket3(冯翼)/`*
> 3. **突发意外绝对不关机**：赛场摔倒、脱力倒地、掉棒时严禁移开镜头！同伴飞奔搀扶、递水与拍背擦汗是主片与学生会宣传片最珍贵的黄金素材。
