## 五、任务单印制守则（摄制、连拍打星与拷卡规范）

> [!IMPORTANT]
> **【任务单底部印制版·摄制与拷卡现场守则】**
> 1. **连拍打星·在精不在多**：严禁无脑连拍堆砌废片！赛隙务必回看机内打星（Rating 1~5星），精简废片率，侧重高信息密度与有效镜头。
> 2. **拷卡三级目录规范**：素材交接严禁随意散落，必须严格遵循三级目录结构：
>    `日期` / `比赛项目` / `机型(拍摄者)`
> 3. **突发意外绝对不关机**：赛场摔倒、脱力倒地、掉棒时严禁移开镜头！同伴飞奔搀扶、递水擦汗是主片与宣传片最珍贵的黄金素材。
